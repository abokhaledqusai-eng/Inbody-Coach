# 🏋️‍♂️ Inbody Coach

A full-stack fitness and nutrition system featuring a mobile client app, trainer progress reporting, and an integrated supplement store.

---

## 📁 Repository Structure

* **`backend/`** — Laravel RESTful API & Admin Panel
* **`mobile/`** — Mobile Application (Flutter / Android)

---

## ✨ Key Features

* **Client & Coach Management:** Role-based authentication and interaction.
* **Workout & Meal Tracking:** Daily logging for fitness activities and customized nutrition plans.
* **Progress Reports:** Weekly automated reporting sent to personal trainers.
* **Supplement Store:** E-commerce functionality for nutrition products and orders.

---

## 🛠️ Tech Stack

* **Backend:** Laravel (PHP), RESTful APIs, MySQL
* **Mobile:** Mobile App Framework
* **Version Control:** Git & GitHub

---

## 🚀 Quick Setup

### Backend
1. `cd backend`
2. `composer install`
3. `cp .env.example .env` && `php artisan key:generate`
4. `php artisan migrate`
5. `php artisan serve`
